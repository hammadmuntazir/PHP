# PHP Practice

A collection of PHP fundamentals and small examples for learning server-side scripting.

## Topics represented

- Variables, types, operators, and conditionals
- Loops and string/number operations
- GET, POST, request handling, and superglobals
- Cookies and session variables

## Run locally

Install PHP and verify it is available:

```bash
php --version
```

From the repository root, run an individual CLI-compatible script with `php filename.php`. For web examples, use a local PHP server and inspect the specific file's requirements before running it.

## Scope

These are learning examples, not a complete production backend. This repository shows earlier web-development practice and is secondary to my current Data Engineering focus.
